# Roadmap

Status legend: `[ ]` not started · `[~]` in progress · `[x]` done. Feature IDs refer to `docs/product/v1-scope.md`. Production is deployed once at the end of each phase (`docs/workflow.md`).

**V1 complete (owner, 2026-10-20):** every feature and automation of `docs/product/v1-scope.md` (Phases 0 to 4) is delivered and runs in production (`3a914f5`). One launch item stays open by the owner's choice: off-server backups and a tested restore wait until a storage service is subscribed (ADR 0034); until then backups exist on the server only. V2's direction is approved (`docs/product/v2-scope.md`, 2026-10-20): the Hub track below; accounting is built in parallel as Vertex Mizan, tracked in its own repository (ADR 0035). The V1 success metrics (`v1-scope.md` §8) are measured around 2026-12-19, two months after all users were onboarded.
