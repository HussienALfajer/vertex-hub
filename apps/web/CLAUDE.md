# apps/web

React 19 + Vite SPA, Arabic RTL first. Read `brand/identity.md` before visual work. Conventions: ADR 0013 (Web), ADR 0003.

## Layout
- `src/routes/`: TanStack Router file routes. Keep them thin: guard, loader, then a page component. `routeTree.gen.ts` is generated by the router plugin: never edit it.
- `src/features/<module>/`: one folder per domain: `<module>.queries.ts` (query options and mutations), page components, forms.
- `src/components/`: app-wide pieces (shell). `src/lib/`: infrastructure (auth, format, theme). `src/i18n/locales/ar.json`: every UI string.
- Pattern to copy: `src/features/users/` (queries, list page with URL filters, form, detail page with actions) and `src/routes/_app/team/` (thin routes). A profile with tabs in the URL, dialogs per child record and a whole-record form: `src/features/clients/`. Confirmations: `src/components/confirm-dialog.tsx`. Forms: React Hook Form + contract schema + `standardSchemaResolver`; errors through `errorMessage()` and `FormAlert`.
- The signed-in user: `useMe()`; permission checks: `can(me, permission)` (`src/lib/auth.ts`).

## Rules
- UI comes from `@vertex-hub/ui` only. No ad-hoc colors, fonts, spacing or raw hex values. Missing component: add it to `packages/ui`, not here.
- Logical CSS only (`ms-*`, `ps-*`, `start-*`, `text-start`). `packages/ui/src/conventions.test.ts` checks this file tree too.
- No hard-coded user-facing text: `t('<feature>.<key>')`, shared strings under `common`. Arabic copy follows `brand/identity.md` §9.
- Numbers and dates only through `src/lib/format.ts` (`ar-u-nu-latn`, `Asia/Damascus`).
- Server state in TanStack Query. Query keys start with the module name. API calls go through `api` and `call()` in `src/lib/api/client.ts`, typed from the OpenAPI document (`schema.gen.ts`, generated: never edit). After an API change: `pnpm --filter @vertex-hub/api openapi:export`, then `pnpm --filter @vertex-hub/web api:generate`. Better Auth calls use `authClient`.
- Forms validate with the same Zod schema from `@vertex-hub/contracts` that the API uses.
- Permission checks in the UI only hide things (`me.permissions`); the API enforces them.
- Every page handles loading, empty and error states. Server errors show the translation of their `code` (`errors.<code>`), never the raw message.
- Accessible by default: labelled inputs (`Field`/`FieldLabel`), `role="alert"` for errors, real buttons and links.

## Tests
- Unit: `*.test.ts` next to the code (Vitest).
- E2E (`e2e/`): the API is mocked in `e2e/fixtures.ts` with contract types. Every new screen gets RTL screenshots in both themes in `e2e/screens.spec.ts`.

Run: `pnpm --filter @vertex-hub/web test` · `pnpm test:e2e` (builds first) · `pnpm --filter @vertex-hub/web typecheck`.
